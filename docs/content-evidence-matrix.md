# Content Evidence Matrix

Audit date: 2026-08-20. Scope: the organization-controlled public legacy site at `https://giftingwithoutborder.org/`, direct materials supplied by the project owner, and the local recovery recorded in `docs/asset-inventory.md`.

## Evidence classes

- **Class A — authoritative:** current, dated organization-published reports, governance material, verified payment instructions, or approved stories with the information needed for safe publication.
- **Class B — historical context:** material published on the organization-controlled legacy site, or a directly supplied owner asset with clear placement direction. It can establish a historical public description or visual association, but cannot establish a current fact, result, date, location, person, consent, or financial instruction unless the owner separately and explicitly authorizes that exact current use.
- **Class C — not safe to reuse:** content that is absent, undated, incomplete, unsupported, third-party, or otherwise cannot meet the required publication boundary.

No Class A source was located in this audit. An owner instruction can authorize a specified presentation choice; it does not promote adjacent legacy screenshot details into Class A evidence.

## Implementation boundary

This milestone uses selected Class B material to make the public history legible without recreating the legacy interface. Screenshots remain audit evidence and are not copied into public assets. Class C material is not copied into the product. The next publication step for every pending area is the approval and verification process in `docs/content-readiness.md`, not additional inference from legacy material.
