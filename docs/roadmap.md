# Roadmap

## Phase 1 — Foundation

**Complete.** Project bootstrap, design tokens, typography, colors, global styles, root layout, and the Homepage scaffold are established.

## Phase 2 — Global Shell

**Complete.** Responsive containers, Header, mobile navigation, Footer, skip link, focus treatment, and reduced-motion support are in place.

## Phase 3 — Homepage

**Architecturally complete.** The locked seven-section sequence is intact. Authentic logo and selected legacy project media are integrated, but some public-facing reporting and voice content remains content-pending.

## Phase 4 — Core Pages

**Implemented; authoritative content remains pending.**

| Area | Current state |
| --- | --- |
| About | Implemented with Mission, Vision, Values, leadership-pending state, and Ways to Support; approved organizational content is still required. |
| Projects | Implemented from verified legacy records with static detail routes; current project status, dates, locations, and outcomes are pending. |
| Impact | Content-ready; verified metrics, methodology, and reporting are pending. |
| Stories | Content-ready; approved, consented stories are pending. |
| Donate | Structurally implemented; independently verified payment data is pending. |

## Phase 5 — Content Layer, SEO, and Analytics

**Deferred.** No MDX publishing system, SEO implementation, metadata expansion, or analytics work begins until governance review and authoritative content inputs are available.

## Phase 6 — Payment Integrations

**Deferred.** Payment providers and bank-transfer instructions require independent organizational verification before any integration or public activation.

## Phase 7 — Deployment

**Deferred.** Vercel deployment and production-readiness work follow approved content, payment, and release decisions.

## Entry criteria

- **Phase 4 to Phase 5:** governance documentation accepted; organization, project, and content approval owners identified; no unresolved factual claims.
- **Phase 5 to Phase 6:** approved giving policy and independently verified payment-channel details; security and donor-support ownership defined.
- **Phase 6 to Phase 7:** production content approved; payment behavior verified where activated; deployment configuration, performance review, and release ownership confirmed.
